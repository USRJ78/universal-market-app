## ⚡ Key Features

- **Multi-Agent Swarm Bot**: Agents Alpha (Momentum), Beta (Vol Compression), Gamma (Options Geometry), and Delta (Risk Overseer).
- **Zero Net Debit 1x2 Ratio Call Spread Strategy**: High probability upside convexity with hard-capped downside risk.
- **Black-Scholes IV Surface & Skew Arbitrage Engine**: Real-time volatility surface modeling and delta-neutral execution on Delta Exchange.
- **24/7 Cloud Execution**: Fully automated systemd daemon for continuous market scans on AWS EC2 & Oracle Cloud.
- **Standalone Mobile Web App MVP**: Responsive PWA interface for live radar conviction monitoring on iPhone and Android.
